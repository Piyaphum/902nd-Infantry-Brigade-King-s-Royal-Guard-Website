# 902nd Infantry Brigade King's Royal Guard Website

This repository contains the source code for the official website of the 902nd Infantry Brigade, King's Royal Guard (กรมทหารราบที่ 902 รักษาพระองค์).

## Project Overview

The website is designed to provide information about the brigade, its history, commanders, missions, and current news. It includes both a public-facing website and an administrative dashboard for managing content.

## Features

- Public Website:
  - Home Page: Latest news and announcements.
  - About Us: History and background of the brigade.
  - Commanders: List of current and past commanders.
  - Missions: Key missions and responsibilities.
  - Contact Information.
- Admin Dashboard:
  - Authentication system for administrators.
  - Content management interface for updating news and announcements.

## Technology Stack

- HTML5
- CSS3 (Custom styling, responsive design)
- JavaScript (Vanilla JS for interactivity)
- Fonts: Kanit and Sarabun (Google Fonts)

## Directory Structure

- `/`: Main HTML files for the public website.
- `/admin`: Administrative dashboard pages.
- `/css`: Stylesheets for the public site and dashboard.
- `/js`: JavaScript files for interactivity and data handling.
- `/pages`: Additional content pages (e.g., about, commanders, missions).
- `/images`: Static image assets.
- `/docs`: Project documentation and plans.
